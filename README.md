# DASBOB keyboard sources

This repo is an archive for all the resources I used for my DASBOB keyboard.

I just git cloned the current latest commits of the following repositories:

| Repo                                          | Commit                                    | Commit timestamp   | Archived at |
| --------------------------------------------- | ----------------------------------------- | ------------------ | ----------- |

| https://github.com/GroooveBob/DASBOB-qmk.git  | b6f7f6f0164e3f5b44c989333c0500173ed06eaf  | 2023-12-22         | 2026-10-17  |


- [beekeeb/DASBOB Keyboard _ beekeeb.pdf](beekeeb/DASBOB Keyboard _ beekeeb.pdf) is the beekeeb instructions page for the keyboard
- [beekeeb/dasbob_vial_rp2040.uf2](beekeeb/dasbob_vial_rp2040.uf2) is a prebuilt firmware by beekeeb

[KiCad](https://www.kicad.org/) can be used to inspect the PCB schematics. (`brew install --cask kicad`)
